# 现场抽奖工具

一个纯前端、适合手机与 iPad 浏览器现场操作的轻量抽奖网页。配置保存在当前浏览器本地，不自动同步到其他设备。

## 文件结构

- `index.html`：抽奖主页面
- `settings.html`：抽奖设置页面
- `preview.html`：双页面预览入口
- `assets/styles.css`：公共样式
- `assets/logic.js`：概率计算、本地存储与配置校验
- `assets/app.js`：抽奖页交互
- `assets/settings.js`：设置页交互

## 运行方式

直接在浏览器中打开 `index.html` 即可使用。

若希望通过本地静态服务预览，可在 `lottery/` 目录执行：

```bash
npm run preview
```

然后访问：

- `http://localhost:8080/index.html`
- `http://localhost:8080/settings.html`
- `http://localhost:8080/preview.html`

若要给同一局域网内的手机或 iPad 访问，请将 `localhost` 替换为电脑当前局域网 IP，例如：

- `http://192.168.x.x:8080/index.html`
- `http://192.168.x.x:8080/settings.html`

## 浏览器验收

可执行：

```bash
npm run check:browser
```

该脚本会完成主要视口截图、保存/取消/刷新检查，以及关键边界验收。

## 验收要点

1. 在设置页新增、编辑、删除奖品，点击“保存设置”后返回首页并生效。
2. 修改但点击“取消修改”时，不写入本地存储。
3. 刷新页面后，已保存配置仍保留。
4. 奖品总概率超过 `100%` 时禁止保存，并给出明确提示。
5. `0%` 的奖品仍可展示，但不会被抽中。
6. 奖品总概率为 `100%` 时，“谢谢参与”为 `0%`，每次必定中奖。
7. 抽奖动画在开始前先确定结果，最终停在对应奖品扇区。
8. 抽奖过程中按钮锁定，连续点击不会重复触发。

## 说明

- 手机和 iPad 的配置分别保存在各自浏览器中，互不自动同步。
- 若浏览器禁用了本地存储或保存失败，页面会显示失败提示，不会误报“保存成功”。
- 若系统开启“减少动态效果”，转盘动画会自动缩短或关闭。
